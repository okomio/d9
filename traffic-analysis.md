**Scope:** the Infrastructure CMS instance, including all its collection traffic, in a 14-day production gateway-log sample from 30 September–14 October 2026. Usage descriptions replace exact traffic counts. Anonymous labels represent observed caller signatures and may cover multiple clients; they are not verified account identities.

**Decision:** P0 is the first regression-test tranche; P1 still receives smoke/contract tests. Ranking weighs automated usage, authentication dependencies and write/schema risk. It is a test order, not permission to break lower-volume routes. Use the existing contracts in [endpoint-inventory.md](endpoint-inventory.md), especially Items queries/envelopes, authentication and GraphQL. Unranked inventory routes remain unmeasured, not proven unused.

**Attribution limit:** inspected gateway records did not expose verified Directus user identities or authorization-header credentials. No URL-token observations were found for this scope. Caller A–D denote signature cohorts only; users, token owners and static-token/JWT classification remain unresolved. Resolve legacy default namespaces from authenticated account ownership, never from these labels or user agents.

**Evidence and sanitization:** ranking uses aggregated Infrastructure gateway observations and limited endpoint/caller samples, including successful GET examples for each automated group and observed editor writes. This measures gateway-visible traffic only; request bodies and response payloads were not inspected. Exact metrics, runtime/service identifiers, account identifiers, credential fingerprints and internal log-access coordinates remain redacted.
